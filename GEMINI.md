# Antigravity Rules

Sempre que for criar algo na web, utilize o Python. Podendo usar tanto o Django quanto o Flask.
Crie ambiente virtual, tentando primeiramente com uv, caso não consiga, faça via python -m venv.
Comece sempre fazendo o plan, para após, questionar se está tudo correto com o solicitante, e, caso aprovado, iniciar o desenvolvimento.
Sugira sempre criar o .gitignore com a estrutura de itens importantes para ignorar, como binários, logs, credenciais, etc.
